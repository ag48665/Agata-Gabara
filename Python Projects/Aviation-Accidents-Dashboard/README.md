# ✈️ Aviation Accidents Dashboard

## 📊 Project Overview

This project analyzes aviation accident data and presents key insights using an interactive dashboard built with Python.

The dashboard provides visualizations and statistics such as:

* Number of accidents per year
* Average number of fatalities per accident
* Top 10 countries with the most accidents
* Distribution of accidents by weather conditions
* Average number of casualties by weather

## 🚀 How to Run the Project

### 1. Install dependencies

Open terminal and run:

```
pip install pandas matplotlib streamlit
```

### 2. Navigate to project folder

```
cd PythonProject5
```

### 3. Run the dashboard

```
streamlit run dashboard.py
```

## 📈 Features

### 🔹 Accidents Over Time

Displays how the number of accidents changes yearly.

### 🔹 Average Fatalities per Accident

### 🔹 Weather Conditions

Breakdown of accidents depending on weather.
